# Program 05 — Customize a Line Plot

## Objective

Learn how to customize the appearance of a line chart.

## Concepts

marker
linestyle
linewidth
grid

## Example

marker="o"

Adds a marker at each data point.

linestyle="--"

Creates a dashed line.

linewidth=2

Controls line thickness.

plt.grid(True)

Displays grid lines.

## Run

python 05_customize_line_plot.py

## Expected Result

A weekly sales line chart with:

- circular markers
- dashed line
- thicker line
- grid
- axis labels
- title
