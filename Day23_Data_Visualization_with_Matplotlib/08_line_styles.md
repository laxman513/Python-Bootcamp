# Program 08 — Line Styles

## Objective

Learn how to use different line styles to distinguish datasets.

## Concepts

linestyle
marker
label
legend

## Common Line Styles

"-"  → solid
"--" → dashed
":"  → dotted
"-." → dash-dot
