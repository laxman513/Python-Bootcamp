# Program 07 — Markers

## Objective

Learn how to highlight individual data points using markers.

## Concept

marker="o"

places a circular marker on each data point.

## Example

plt.plot(months, sales, marker="o")

## Common Markers

"o" → circle
"s" → square
"^" → triangle
"*" → star
"x" → x marker
