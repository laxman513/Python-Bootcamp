# Program 29 — Employee Analytics Analysis

## Objective

Create reusable analysis functions for the Employee Analytics Dashboard.

## Functions

The program should calculate:

1. Salary statistics
2. Department statistics
3. High earners
4. Experience statistics
5. Top employees

## Concepts

- Functions
- Pandas
- GroupBy
- Filtering
- Sorting
- DataFrame operations
- Reusable analysis logic

## Run

python 29_employee_analytics_analysis.py

## Expected Result

The program prints:

- Average salary
- Minimum salary
- Maximum salary
- Department salary summary
- High earners
- Top employees

## Key Learning

Separate analysis logic from visualization logic.

This is an important software-engineering practice.
