# Program 06 — Multiple Lines

## Objective

Learn how to display multiple datasets on the same graph.

## Concepts

- Multiple plt.plot() calls
- label
- plt.legend()
- Comparing datasets

## Dataset

We compare monthly sales for:

- 2025
- 2026

## Key Point

Each call to plt.plot() adds another line to the same chart.

## legend()

plt.legend() displays the labels assigned to each line.

## Run

python 06_multiple_lines.py

## Expected Result

A chart containing two lines:

- 2025 sales
- 2026 sales
