# Program 01 — Import Matplotlib

## Objective

Learn how to import Matplotlib and verify its installation.

## Concept

Matplotlib is a Python library used for data visualization.

The most commonly used module is:

matplotlib.pyplot

It is usually imported as:

import matplotlib.pyplot as plt

## Run

python 01_import_matplotlib.py

## Expected Output

Matplotlib imported successfully.
Matplotlib version: <version>

## Key Point

plt is the conventional alias for matplotlib.pyplot.
