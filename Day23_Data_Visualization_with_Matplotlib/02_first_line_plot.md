# Program 02 — First Line Plot

## Objective

Create the first line chart using Matplotlib.

## Concepts

- plt.plot()
- plt.show()

## Data

X values:

1, 2, 3, 4, 5

Y values:

2, 4, 6, 8, 10

## Expected Result

A line graph should appear showing an increasing straight line.

## Important

plt.plot() creates the plot.

plt.show() displays the plot.
