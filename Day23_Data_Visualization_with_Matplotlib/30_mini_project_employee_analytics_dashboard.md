# Program 30 — Employee Analytics Dashboard

## Final Day 23 Mini Project

## Objective

Build a complete Employee Analytics Dashboard using Pandas and Matplotlib.

## Dashboard

The dashboard contains four visualizations:

1. Employee count by department
2. Average salary by department
3. Experience vs salary
4. Salary distribution

## Additional Analysis

The program also displays:

- Average salary
- Minimum salary
- Maximum salary
- Average experience
- High earners
- Highest-paid employee
- Largest department

## Technologies

- Python
- Pandas

- Matplotlib
- pathlib

## Business Questions

The dashboard should help answer:

1. Which department has the most employees?
2. Which department has the highest average salary?
3. Is experience related to salary?
4. How are salaries distributed?
5. Who are the highest-paid employees?
