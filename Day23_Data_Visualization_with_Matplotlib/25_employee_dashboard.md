# Program 25 — Employee Dashboard

## Objective

Create a simple employee analytics dashboard using Pandas and Matplotlib.

## Dashboard Sections

1. Employee count by department
2. Average salary by department
3. Experience vs salary
4. Salary distribution

## Concepts

- Pandas
- Matplotlib
- GroupBy
- Value counts
- Scatter plot
- Histogram
- Subplots
- Data cleaning
- Exploratory Data Analysis

## Workflow

CSV
 ↓
Pandas
 ↓
Clean missing values
 ↓
Calculate statistics
 ↓
Create visualizations
 ↓
Employee Dashboard

## Run

python 25_employee_dashboard.py

## Expected Result

One window containing four visualizations.

## Business Questions

The dashboard should help answer:

1. Which department has the most employees?
2. Which department has the highest average salary?
3. Does experience appear related to salary?
4. How are salaries distributed?

## Key Learning

A dashboard combines multiple visualizations to communicate several insights at once.
