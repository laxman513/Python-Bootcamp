# Program 04 — Labels and Title

## Objective

Learn how to make charts understandable using labels and titles.

## Functions

plt.xlabel()
plt.ylabel()
plt.title()

## Example

X-axis:

Day

Y-axis:

Sales

Chart title:

Weekly Sales

## Run

python 04_labels_and_title.py

## Key Point

A good visualization should clearly communicate what the axes represent.
