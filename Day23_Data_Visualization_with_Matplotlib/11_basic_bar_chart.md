# Program 11 — Basic Bar Chart

## Objective

Learn how to create a basic vertical bar chart.

## Concepts

- plt.bar()
- Categories
- Numerical values
- X-axis and Y-axis

## Data

Departments:

IT, HR, Finance, Sales

Employees:

40, 25, 20, 35

## Key Point

A bar chart is useful for comparing different categories.

## Run

python 11_basic_bar_chart.py

## Expected Result

A vertical bar chart showing the number of employees in each department.
