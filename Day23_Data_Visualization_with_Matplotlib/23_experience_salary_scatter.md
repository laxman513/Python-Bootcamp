## Objective

Visualize the relationship between employee experience and salary.

## Concepts

- Pandas
- Scatter plot

## Tasks

2. Remove rows where Experience or Salary is missing.
3. Create a scatter plot.
4. Put Experience on X-axis.
5. Put Salary on Y-axis.

## Run

python 23_experience_salary_scatter.py
