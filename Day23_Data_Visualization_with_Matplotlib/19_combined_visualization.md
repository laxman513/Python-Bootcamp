# Program 19 — Combined Visualization

## Objective

Create multiple visualizations from the same employee dataset.

## Charts

1. Bar chart — department employee count
2. Scatter plot — experience vs salary
3. Histogram — salary distribution

## Concepts

- Multiple plots
- `plt.subplot()`
- Bar chart
- Scatter plot
- Histogram
- Data analysis

## Why?

A single chart rarely tells the complete story.

Different charts answer different questions.

## Questions

Bar chart:
Which department has the most employees?

Scatter plot:
Does salary increase with experience?

Histogram:
How are salaries distributed?
