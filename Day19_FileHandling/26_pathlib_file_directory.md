# Program 26 — Checking Files and Directories

## Objective

Learn how to determine whether a path is a file or directory.

## Concepts

- Path
- exists()
- is_file()
- is_dir()

## Methods

exists()
→ Does the path exist?

is_file()
→ Is the path a file?

is_dir()
→ Is the path a directory?

## Expected Output

For output.txt:

Exists: True
Is File: True
Is Directory: False

For Day19_FileHandling:

Exists: True
Is File: False
Is Directory: True
