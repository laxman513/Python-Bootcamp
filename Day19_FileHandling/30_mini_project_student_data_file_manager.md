# Program 30 — Student Data File Manager

## Objective

Build a complete menu-driven Student Data File Manager.

## Features

1. Add Student
2. List Students
3. Search Student
4. Exit

## Storage

Student data is stored in:

data/students.json

## Concepts Used

- pathlib
- JSON
- File handling
- with open()
- Exception handling
- Functions
- Lists
- Dictionaries
- Loops
- User input
- CRUD-style data management

## Expected Behavior

The application should allow the user to:

- Add students
- View all students
- Search students by name
- Exit the application

Student data must remain available after the program exits.

## Run

python 30_student_data_file_manager.py
