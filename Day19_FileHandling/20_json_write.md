# Program 20 — Writing JSON

## Objective

Learn how to convert Python data into JSON and save it to a file.

## Concepts

- JSON
- Python dictionary
- json module
- json.dump()
- with open()
- UTF-8 encoding

## What is JSON?

JSON stands for JavaScript Object Notation.

It is a common format for storing and exchanging structured data.

Example:

{
    "name": "Rahul",
    "age": 20,
    "marks": 85
}

## Important Function

json.dump()

It writes Python data directly into a JSON file.
