# Program 18 — Writing Data to a CSV File

## Objective

Learn how to create and write data into a CSV file using Python.

## Concepts

- csv.writer()
- writerow()
- writerows()
- CSV header
- Writing multiple rows

## Steps

1. Open students_output.csv in write mode.
2. Create a CSV writer.
3. Write the header.
4. Write student records.
5. Close the file automatically using with.

## Expected File

students_output.csv

Contents:

Name,Age,Marks
Rahul,20,85
Priya,21,92
Arjun,19,78
