# Program 29 — Student Data Manager Functions

## Objective

Create reusable functions to manage student data stored in JSON.

## Functions

1. load_students()
2. save_students()
3. add_student()
4. list_students()
5. search_student()

## Student Structure

Each student will contain:

- id
- name
- age
- marks

Example:

{
    "id": 1,
    "name": "Rahul",
    "age": 20,
    "marks": 85
}

## Expected Output

Student added successfully.

Student List:
1 - Rahul - 20 - 85

Search Result:
1 - Rahul - 20 - 85
