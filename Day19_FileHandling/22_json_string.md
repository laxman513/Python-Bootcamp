# Program 22 — JSON Strings

## Objective

Learn how to convert between Python dictionaries and JSON strings.

## Concepts

- json.dumps()
- json.loads()
- JSON string
- Python dictionary

## Important Functions

json.dumps()

Python object → JSON string

json.loads()

JSON string → Python object

## Difference

dump / load

are generally used with files.

dumps / loads

are generally used with strings.

## Expected Output

JSON String:
{"name": "Rahul", "age": 20, "marks": 85}

Python Dictionary:
{'name': 'Rahul', 'age': 20, 'marks': 85}
