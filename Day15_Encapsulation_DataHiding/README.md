# Day 15 - Encapsulation, Properties and Advanced Property Inheritance

This folder contains the Day 15 practice work.

## Files
- `program01.py` to `program40.py` - 40 numbered practice programs
- `mini_project.py` - BankAccount and SavingsAccount mini-project
- `Notes.md` - Day 15 notes
- `Interview_Questions.md` - interview revision

## Main Topics
Encapsulation, private attributes, `__dict__`, getters/setters, `@property`,
read-only and calculated properties, validation, inheritance, property
overriding, `super()`, `fget`, `fset`, and parent setter reuse.
