# Program 03 — Create a DataFrame

## Objective

Create a Pandas DataFrame from a list of lists.

## Concepts

- DataFrame
- Rows
- Columns
- Column names

## Structure

A DataFrame is a two-dimensional labeled data structure.

It consists of:

- Rows
- Columns
- Index

## ML Connection

Most machine learning datasets are represented as rows and columns.

For example:

Age | Experience | Salary
--- | --- | ---
25 | 2 | 50000
30 | 5 | 70000
