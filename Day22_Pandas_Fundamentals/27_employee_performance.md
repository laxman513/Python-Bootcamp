# Program 27 — Employee Performance Analysis

## Objective

Create derived columns and perform multi-condition analysis.

## Concepts

- Derived columns
- Vectorized calculations
- np.where()
- Boolean filtering
- Multiple conditions
- Sorting
- Feature engineering

## Tasks

1. Create an Experience_Level column.
2. Create a Salary_Category column.
3. Find experienced employees.
4. Find employees with both high experience and high salary.
5. Sort employees by salary.

## Experience Level

Experience >= 8:
    Senior

Experience < 8:
    Junior

## Salary Category

Salary >= 70000:
    High

Salary < 70000:
    Normal

## Run

python 27_employee_performance.py
