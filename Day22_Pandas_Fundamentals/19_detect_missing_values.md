# Program 19 — Detect Missing Values

## Objective
Learn how to detect missing values in a DataFrame.

## Concepts
- isna()
- isnull()
- sum()
- Counting missing values

## Important

df.isna()

returns True where a value is missing.

df.isna().sum()

counts missing values in each column.
