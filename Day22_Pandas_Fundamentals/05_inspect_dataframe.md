# Program 05 — Inspect a DataFrame

## Objective

Learn how to inspect a Pandas DataFrame.

## Methods

### shape

Returns:

(rows, columns)

### columns

Returns column names.

### dtypes

Returns the data type of each column.

### head()

Displays the first rows.

### tail()

Displays the last rows.

## ML Connection

Before training a machine learning model, we need to understand the dataset.

Dataset inspection is an important part of data preprocessing.
