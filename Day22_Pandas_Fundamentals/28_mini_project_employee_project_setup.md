# Program 28 — Employee Data Analyzer Setup

## Objective

Create the initial employee dataset for the Pandas Mini Project.

The program will:

1. Create an employee dataset
2. Include some missing values
3. Convert the dataset into a Pandas DataFrame
4. Create a data directory
5. Save the DataFrame as employees.csv

## Concepts Used

- Pandas DataFrame
- NumPy
- Missing values
- NaN
- pathlib
- to_csv()
- CSV files

## Dataset Columns

- Employee_ID
- Name
- Department
- Age
- Experience
- Salary

## Important

This program creates the CSV file required by Programs 29 and 30.

## Run

python 28_employee_project_setup.py

## Expected Result

A file should be created:

data/employees.csv

## Checklist

- [ ] DataFrame created
- [ ] Missing values included
- [ ] CSV file created
- [ ] employees.csv exists inside data folder
