# Program 13 — Drop a Column

## Objective
Learn how to remove a column from a DataFrame.

## Concepts
- drop()
- axis=1
- inplace

## Syntax

df.drop("ColumnName", axis=1)

## Important
axis=1 means column.

axis=0 means row.

## Expected Output
The selected column should be removed.

## Run
python 13_drop_column.py
