# Program 10 — Filtering DataFrame Rows

## Objective

Learn how to filter DataFrame rows using conditions.

## Syntax

df[df["column"] > value]

## Examples

df[df["Salary"] > 70000]

df[df["Age"] >= 30]

## Concept

Pandas creates a Boolean condition and uses it to select rows.

## ML Connection

Filtering is commonly used during:

- Data exploration
- Data cleaning
- Feature analysis
- Dataset preparation
