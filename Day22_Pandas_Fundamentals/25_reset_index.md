# Program 25 — reset_index()

## Objective
Understand how groupby() changes the DataFrame index and how to convert it back into a normal column.

## Concepts
- Index
- reset_index()
- GroupBy result
- DataFrame conversion

## Key Point

groupby() often produces a result where the grouping column becomes the index.

reset_index() converts that index back into a regular column.
