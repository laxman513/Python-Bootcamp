# Program 21 — NumPy reshape()

## Objective

Learn how to change the shape of a NumPy array without changing
the underlying values.

## Concepts

- reshape()
- Rows
- Columns
- Array shape

## Syntax

array.reshape(rows, columns)

## Important Rule

The total number of elements must remain the same.

For example:

6 elements can become:

(2, 3)
(3, 2)
(1, 6)
(6, 1)

python 21_array_reshape.py
