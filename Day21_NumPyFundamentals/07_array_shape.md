# Program 07 — Array Shape

## Objective

Learn how to find the shape of a NumPy array.

## Concept

The `shape` attribute returns the size of the array along each dimension.

## Examples

A 1D array with 5 elements:

(5,)

A 2D array with 2 rows and 3 columns:

(2, 3)

## Run

python 07_array_shape.py
