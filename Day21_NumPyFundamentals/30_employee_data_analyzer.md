# Program 30 — Employee Data Analyzer

## Mini Project

Employee Data Analyzer using NumPy.

## Objective

Build a small data-analysis application using NumPy.

## Dataset

Each employee contains:

- Employee ID
- Age
- Experience
- Salary

## Features

The program should:

1. Display all employees.
2. Display employee IDs.
3. Calculate average age.
4. Calculate average experience.
5. Calculate average salary.
6. Find minimum salary.
7. Find maximum salary.
8. Find employees earning more than 70000.
9. Find the oldest employee.
10. Find the most experienced employee.

## NumPy Concepts Used

- np.array()
- indexing
- slicing
- shape
- np.mean()
- np.min()
- np.max()
- np.argmax()
- Boolean filtering
