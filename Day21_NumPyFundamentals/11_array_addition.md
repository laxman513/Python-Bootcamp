# Program 11 — NumPy Array Addition

## Objective

Learn how NumPy performs element-wise addition between arrays.

## Concepts

- Element-wise operation
- NumPy array addition
- Vectorized operations

## Steps

1. Create two NumPy arrays.
2. Add them using `+`.
3. Print the result.

## Expected Output

Array 1: [10 20 30 40]
Array 2: [ 1  2  3  4]
Addition: [11 22 33 44]

## Run

python 11_array_addition.py
