# Program 01 — Import NumPy

## Objective

Learn how to import NumPy and verify that it is installed correctly.

## Concepts

- NumPy
- `import`
- NumPy alias `np`
- Checking NumPy version

## Steps

1. Import NumPy using the standard alias `np`.
2. Print the NumPy version.
3. Verify that NumPy is working correctly.

## Expected Output

The exact version may differ.

Example:

NumPy version: 2.x.x

## What to Verify

- NumPy imports without an error.
- A NumPy version is displayed.

## Run

From the Day21 folder:

python 01_import_numpy.py
