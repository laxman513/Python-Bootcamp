# Program 02 — Create NumPy Array

## Objective

Learn how to create a NumPy array from a Python list.

## Concepts

- `np.array()`
- NumPy array
- Python list vs NumPy array

## Steps

1. Create a Python list.
2. Convert it into a NumPy array.
3. Print both values.
4. Print their types.

## Expected Output

Numbers: [10, 20, 30, 40, 50]
NumPy Array: [10 20 30 40 50]

Python list type: <class 'list'>
NumPy array type: <class 'numpy.ndarray'>

## Run

python 02_create_numpy_array.py
