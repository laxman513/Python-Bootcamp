# Program 26 — Boolean Filtering

## Objective

Learn how to filter NumPy arrays using conditions.

## Concepts

- Boolean conditions
- Boolean arrays
- Boolean indexing
- Filtering NumPy arrays

## Example

marks = np.array([45, 78, 92, 35, 88, 60])

marks[marks > 60]

## Expected Result

[78 92 88]

## Key Point

NumPy allows us to filter arrays without explicitly writing a Python loop.

This is very useful in data analysis and machine learning.
