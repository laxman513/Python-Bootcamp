# Program 17 — Lambda Functions

## Objective
Learn how to create small anonymous functions using lambda.

## Concepts
- lambda syntax
- lambda with one parameter
- lambda with multiple parameters
- lambda vs normal function

## Syntax

lambda arguments: expression

## Example

square = lambda x: x * x

print(square(5))

## Expected Output

25

## Key Point

A lambda function is normally used for a small function that contains a single expression.
