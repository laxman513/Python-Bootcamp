# Program 12 — Flexible Student Function

## Objective

Build a function that accepts a student name, any number of marks,
and additional student information.

## Concepts

- *args
- **kwargs
- sum()
- len()
- Dictionary
- Tuple

## Expected Output

Student: Rahul
Marks: (85, 78, 92)
Average: 85.0
City: Hyderabad
Course: Python

## Run

python 12_flexible_function.py
