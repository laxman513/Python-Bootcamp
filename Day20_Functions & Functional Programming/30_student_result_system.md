# Program 30 — Student Result System

## Objective

Build a complete student result processing application.

## Concepts Used

- Functions
- Parameters
- Return values
- *args
- Lambda
- map()
- filter()
- List comprehension
- Higher-order functions
- Conditional statements
- Lists
- Dictionaries
- __name__ == "__main__"

## Features

- Store student information
- Process marks
- Calculate average
- Determine PASS/FAIL
- Determine grade
- Display result
